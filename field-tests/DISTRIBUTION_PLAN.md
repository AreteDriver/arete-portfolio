# Ethical distribution and measurement

## Publishing
- Publish a reproducible case only after G4 verification.
- Link upstream project, pinned commit, tool version, methodology and limitations.
- Include clean and false-positive results alongside positive findings.
- Use one substantive case to produce a GitHub writeup, technical article and short social summary; do not fabricate endorsements.
- Offer upstream fixes only when they provide confirmed, actionable value. Respect maintainer contribution and security policies.

## Conversion path
Case study → tool README → verified install command → first local result → optional feedback or contribution.

## Measurements (30/60-day checkpoints)
- Eligible repositories evaluated; reproducible cases; confirmed/clean/false-positive ratios.
- External issue/PR acceptance and unsolicited maintainer feedback.
- Independent installations and repeat use **only where observable with consent**.
- Referrals to tool repositories; docs corrections and product improvements.
- Record limitations of GitHub views, package downloads and privacy-preserving local tooling.

No unsolicited bulk PRs, covert telemetry, credentials collection or automated promotional replies. No public employer-specific materials.

# Arete Field Tests

**Real repositories. Reproducible results. Independent evidence.**

Public, reproducible evaluations of Arete tools against independently maintained open-source repositories. This directory is the initial home for the pilot; a separate repository may follow if the program proves useful.

Status: **two external executions recorded; FT-CH-002 independently reproduced on Stheno with scoped human G3 and G4 approval.** The ten-repository cohort is not complete; FT-CH-001 still lacks independent reproduction/review. Tracking: [issue #1](https://github.com/AreteDriver/arete-portfolio/issues/1).

## Pilot
- Ten independent external repositories, initially using [Context Hygiene](https://github.com/AreteDriver/context-hygiene) and [Agent Lint](https://github.com/AreteDriver/agent-lint).
- Select candidates for compatible files and variety, not for likelihood of finding problems.
- Record clean, failed, inconclusive and false-positive outcomes.
- Expand to [MCP Manager](https://github.com/AreteDriver/mcp-manager) after the initial pilot.
